# 🎬 HeyGen 연습장 × Claude

HeyGen(헤이젠)의 핵심 기능을 **15개 미션**으로 하나씩 따라 하며, 각 단계에서 **Claude와 어떻게 협업하는지** 체험하는 인터랙티브 연습 사이트입니다.

👉 사이트: https://yalli2.github.io/heyzen_practice/

## 미션 구성
1. HeyGen 첫 만남 & 요금제 고르기
2. 브랜드 키트 세팅
3. 아바타 종류 고르기 (공개·포토·디지털 트윈·생성)
4. 디지털 트윈 촬영 & Edit Look / Looks 생성
5. Claude로 대본 쓰고 스크립트 박스 다듬기 (쉼·Custom Motion)
6. 목소리: HeyGen Voice, 60초 음성 복제 리허설, Voice Mirroring
7. AI Studio 에디터: 장면·자막·B-roll
8. Video Agent: 프롬프트 빌더 → 스토리보드 승인 → 생성
9. URL·PDF·Figma → 영상, 2인 비디오 팟캐스트
10. 영상 번역: 언어 선택·용어집·Proofread·SRT
11. 인터랙티브 영상(퀴즈·브랜칭) & SCORM
12. LiveAvatar: 페르소나 + 지식베이스 대화 시뮬레이터
13. HyperFrames: HTML/CSS 코드 → 영상 장면
14. Claude ↔ HeyGen MCP 연결 & 도구 호출 시뮬레이터
15. 최종 프로젝트: 파이프라인 조립 & 수료증

각 미션 = 개념 카드 → 따라하기 실습(자동 체크리스트) → Claude 프롬프트(복사 / Claude에서 열기) → 퀴즈 → XP·배지.

## 참고
- HeyGen 공식 사이트가 아닌 **비공식 학습용** 시뮬레이터입니다. 실제 계정·크레딧을 쓰지 않습니다.
- 기능·요금 정보는 2026년 11월 공개 자료 기준이며 바뀔 수 있습니다.
- 진행 상황은 브라우저(localStorage)에만 저장됩니다.
